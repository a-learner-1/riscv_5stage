# CPU5 最小机器 CSR 与 MRET

2026-10-23，基线 `5be17af25087ab82eb85d913b4e37193b83db164`。本阶段为独立 CPU5 接入最小机器 CSR 与 MRET，状态为 **PARTIAL VERIFIED：最小机器 CSR/MRET**，不接正式三级产品。实现范围见 [冻结合同](cpu5_csr_contract_20261023.md)。

## 实现

```verilog
cpu5_top #(.SKELETON_ONLY(0), .ENABLE_FORWARDING(1),
           .ENABLE_CONTROL_FLOW(1), .ENABLE_RAM(1),
           .ENABLE_SYNC_TRAPS(1), .ENABLE_TRAPS(1), .ENABLE_CSR(1),
           .TRAP_VECTOR(32'h00000100)) ...;
```

默认 `ENABLE_CSR=0` 保留前阶段行为。开启时支持 mstatus、mtvec、mscratch、mepc、mcause、mtval、固定 RV32I misa 和只读零值 F11–F15 ID。只接受六种 CSR 指令和精确 MRET 编码。mie/mip、计数器和其他 CSR 精确非法；没有 IRQ、M、MMIO 或 SoC 集成。misa固定值沿用冻结合同，不代表完整ISA合规签核；FENCE等仍未实现，本报告仅验收当前子集。

独立 `cpu5_csr_unit.v` 保存软件状态。CSR 旧值在最老 MEM 从最新提交状态读取，并在同一退休边沿执行 RMW；返回值走 MEM 结果、WB 与现有前递通路。年轻 CSR/MRET 在 ID 保守等待老 CSR/MRET 离开 EX/MEM。MEM 暂停、WB 回压、flush、故障与取消均不能提前或重复更新 CSR。

Trap 使用边沿前已提交 mtvec，保存 mepc/cause/tval，MPIE←MIE、MIE←0。MRET 在 MEM 正常退休，跳到已提交 mepc，MIE←MPIE、MPIE←1、MPP 保持 M，并压制年轻 redirect/新D请求。老已退休 WB 保留；取消纯读按原 owner 协议排空。软件 CSR 写与持久 trap_pc/cause/tval/seq 诊断事件分别保存。取指错误优先于携带指令位可能形成的 CSR 非法检查。

CSR/MRET 不提交 BP 训练。MRET 正常增加 instret，并将退休/WB 的 next-PC 描述符与 arch_next_pc 对齐返回目标。未写 GPR 的 MRET 返回值描述符固定0。
