# BTB 瘦身：第4步验收

结论：保留候选。基线 f115192（D0），固定 64 项；本步独立回归、独立 performance P&R，形成单独本地提交。

## 变更与语义

产品仅修改 rtl/branch_predictor.v 和 rtl/if_stage.v。默认 8192 字 ROM、64 项 BTB 下，每项由 68 bit 缩为 23 bit：7 bit ROM 字地址 tag、13 bit word target、3 bit 六状态编码（四个方向计数状态、INVALID、JAL）。IF 将实际 IMEM_WORDS 传入预测器，查询、训练 PC、训练目标均先对完整地址做 ROM 范围及四字节对齐检查。
容量与两位方向训练策略不变；JAL→条件分支弱向初始化、饱和更新、碰撞替换和普通/JALR 指令的匹配失效保持合法 ROM 域语义。ROM 外查询不命中，ROM 外训练不污染低地址别名，非法目标使当前索引失效。越界行为有意改为不预测，由原 CPU 异常路径处理。

## 功能与性能

默认完整回归 10/10 PASS；原 BTB 测试也通过。新增独立旧 RTL 参考（仅重命名 module），五组参数分别完成 8,258 次 pre/post edge 对照和 28 项定向检查，另 ROM1/BTB1 完成 64 次 edge 与边界检查；覆盖 1/64/1024 项及非二次幂 ROM1000。两套新增合同均 0 Error、0 Warning。
真实 CPU 四模式在旧/新 RTL 均通过：每模式精确退休 17 条、2 次 trap、2 次 MRET、2 次实际 RAM 写；架构轨迹 CSV 逐字节一致，包含 wrong-path squash 和最终寄存器检查。
D0 smoke、smoke-validation 两种子最终 START epoch 测量与基线完全一致：四个窗口/逐事务 CSV 逐字节相同，两份 UART 报告各 62 字段全部一致（BP、I/D-cache、cycle classes、CRC），独立 D0 analyzer 完整 JSON 一致。

| 资源 | D0基线 | 本步 | 差值 |
|---|---:|---:|---:|
| 整体映射 LUT | 8,923 | 8,126 | −797 |
| 整体布线后 LUT | 8,930 | 8,129 | −801 |
| DRM18K 等效 | 36 | 36 | 0 |
| predictor 映射 FF | 3,839 | 1,472 | −2,367 |

逻辑存储 68→23 bit/项不能直接当作物理 FF 百分比。网表实际证明 64×23＝1472 FF（tag448、target832、state192）；target 表读 mux 活跃 lane 为 31→13，完整 32 bit 顺序 PC／输出 mux 仍存在。PDS 将 target 数组提升为 predictor 的 64 个 13 bit 输出，并把读 mux 放入 IF；因此 predictor 子层 LUT2044→956 包含跨层移动，应以整体 LUT 降幅判断收益。IF 汇总 LUT2391→1530、FF4203→1836。
D0 本地 4096×32 RAM 在 map 与 routed netlist 均保持 8 个 DRM18K，D-Cache 两路各 4 个 DRM9K，未绕过 D-Cache。

## 已知记录与证据

D0 两种子仍各有 2 条继承的 irq_external 未连接警告，共 4 条；可选外部 IRQ 被禁用。功能、完整比较门通过，但零警告门不通过，未隐藏或声称消除警告。短程 CoreMark 的 <10 秒提示与 Errors detected 仍属于 smoke 预期；正式成绩必须另行满足 ≥10 秒、CRC 和 Correct operation validated，本步没有正式成绩。
新增 CPU 测试首次在最终 WB 被寄存器堆消费前采样，旧/新实现均失败；随后仅将自建 TB 最终检查移至实际消费沿之后，保留寄存器检查，原失败证据见 targeted_tests/attempt1_terminal_sampling。运行元数据曾写错自建 D0 suite 标记，已按未修改 DO 实际输出 COREMARK D0 ALL TESTS PASS 更正，原日志保留。
STA 审计第一次只接受 wire 数组，未识别 PDS 合法提升为 output 的 target 数组而失败；修正审计解析器，逐项证明 64 个提升端口、caller 连接、832 个目标 FF 与 13 个 mux lane。修前解析器、原 FAIL、补丁和产品/manifest 哈希不变证据见 audit_parser/；产品未为审计修改。
完整证据：build/verification/btb_step4_20261020。sta_comparison.json 含原报告行号和 SHA，targeted_tests 含逐拍/真实CPU/双种子原日志与 CSV，regression_results 含完整回归，pds_performance 含本步独立实现，firmware 含配套固件和报告，baseline 含 D0 对照。
