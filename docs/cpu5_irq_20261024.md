# CPU5 三路机器中断与精确退休边界

2026-10-24，基线 `baa2275d5a2ccb204f23b37414bc7a59f746ecaa`。状态：**PARTIAL VERIFIED：同步机器 IRQ**。本轮接入 external/software/timer 原始电平、mie/mip 与精确中断入口；范围和边沿语义见 [本轮合同](cpu5_irq_contract_20261024.md)。

## 实现

```verilog
cpu5_top #(.SKELETON_ONLY(0), .ENABLE_FORWARDING(1),
           .ENABLE_CONTROL_FLOW(1), .ENABLE_RAM(1),
           .ENABLE_SYNC_TRAPS(1), .ENABLE_TRAPS(1), .ENABLE_CSR(1),
           .ENABLE_RV32M(1), .ENABLE_M(1),
           .ENABLE_EXTERNAL_IRQ(1), .ENABLE_SOFTWARE_IRQ(1),
           .ENABLE_TIMER_IRQ(1)) ...;
// 显式连接 irq_external / irq_software / irq_timer。
```

三路开关默认关闭，旧行为保留。独立 `cpu5_irq_ctrl.v` 对三路分别两级同步；mie 只实现已启用源的 bit11/3/7，mip 反映同步电平且软件写忽略。源撤销由外部提供者负责，本轮没有 MMIO 定时器、软件中断设备或 CPU 自动清源。

每个边沿使用旧 arm 和当前已提交 CSR/pending 复核，external > software > timer。最老同步 fault 优先，其次安全 IRQ，再正常退休。IRQ 与退休互斥，mepc 取边沿前 arch_next_pc，mtval=0；CSR/MRET 的 post 状态只生成下一边沿候选，持续 pending 可在开启中断或 MRET 退休后的紧接边沿进入。

已呈现 STORE 和存活 MEM LOAD 先完成/退休，错误走同步 Trap。未呈现 STORE 可在第一次请求前被抢占。运行中 EX DIV 被取消后继续排空，handler ALU/CSR 可推进，新 ISR MUL 等旧资源释放并使用新 generation。已退休 WB 独立保留，held 的 killed 纯读请求仍稳定并完成发送/排空。

独立审查发现并修复了动态 mip 的提前前递：WB 满或 MEM 暂停时，ID 分支不得先捕获随后变化的 mip。现在仅 mip 的 MEM ready 等待可退休边沿，其他静态 CSR 的既有早前递不变。两类回压均有 ID/EX 正例，移除该门控的真实 RTL 负例被错误分支重定向断言拒绝。

IRQ trap_seq/redirect_seq 是未退休边界诊断，空边界可为全 1、重复或非单调；它不代表已分配的故障指令。退休 seq 的严格单调和唯一性继续独立检查。

## 实测验收

| 检查 | 结果 |
|---|---|
| 控制器/CSR 独立单元 | 全 8 种源配置；4888 次逐边沿控制检查、1112 次 CSR 状态检查；含关闭源、两级同步、候选撤销、post-mie/MIE/MRET、WARL 与 mip 写忽略 |
| 核心定向 | ID/EX 各 27，共 54 场景；284 退休=WB，44 IRQ、6 同步 Trap，6 M 启动=4 消费+2 排空；D 请求/响应闭合 |
| 真实 IF 程序 | ID/EX×BP×I/D 等待×前递开关，共 16 配置；1088 退休=物理 WB、48 IRQ、224 D 请求=响应、1268 I 请求=响应 |
| 取消与恢复 | 16 个运行 DIV 被中断取消并排空；每配置三次 ISR MUL 和返回后的 DIV 使用新 owner；16 个 held 陈旧 IF 错误排空；32 次 MRET 后紧接边沿 IRQ |
| 独立机器字参考 | 12 项 IRQ 固定机器字/状态自检；独立逐周期 raw/两级 pending/旧 arm/提交 CSR/确切 take 边沿；每条退休、CSR 快照、全部 16 词 RAM 与 32 个物理 GPR 对账（21 个已定义含 x0，11 个保持未知） |
| 坏证据 | 11 份 CSV/RAM/GPR 副本破坏均由指定语义检查拒绝；良好输入 SHA 前后不变 |
| RTL 负例 | 单元 15 + 核心 22，共 37 项真实 RTL 功能变异；均先零 Warning/Error 编译，再由指定语义 Fatal 拒绝 |
| 参数 guard | 单元 2 + 核心三源非布尔参数 3，共 5 项独立拒绝，不混入功能变异数量 |
| 兼容链 | 最终同源完整重跑 M→CSR/MRET→Trap→RAM→分支→前递→ALU→IF/默认骨架及各阶段负测；原测试工具未改 |

正常配置全部零 Error/Warning。坏 RTL/非法参数及旧 IF 序号耗尽的 Fatal/非零退出均是指定预期拒绝，不当作正常仿真通过。机器字参考仅复用冻结的 CSR 软件解释器及独立 M 数学函数，不导入 RTL 或测试向量编码器；旧兼容链另外重跑 CSR 30 项、M 42 项自检。

程序在已知 DIV PC=0x30 的首次启动后拉高三源；期望 mepc 独立固定为 0x30，不从 DUT 现场 PC 反推。fixture 在每次入口后撤销相应原始源，代表设备清源；三次 ISR 各将 cause/mepc/status/tval 存入独立 RAM 槽。全部 eligible 边沿的安全性由程序安排独立确定，handler 内访存时 MIE=0。定向测试另覆盖不安全 STORE/LOAD、暂停、flush、旧 WB、源撤销与 64 位 seq 跨 bit32。
