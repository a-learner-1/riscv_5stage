# CPU5 D0 片上数据 RAM 接入验收

日期：2026-10-25；基线：`aad84b44eae382cf243a4929a3114c5db6980198`（S14）。状态：**PARTIAL VERIFIED: CPU5 optional D0 local data RAM routing**。

CPU5 已新增可选 D0 本地同步数据 RAM 路由。`ENABLE_D0_BRAM=0` 默认沿用 AXI；开启后普通 RAM 地址走原同步 RAM 端点，其他后端访问继续走 AXI。上游本地 MMIO、机器设备和 native IF 保持原接口。本次只新增两个产品封装；所有基线 RTL 原文保持不变，正式三级板顶和发布包未替换。

## 实现与合同

- [后端封装](../rtl/cpu5_d0_backend.v)：复用 `dmem_region_router`、`soc_data_mem`、`dmem_axi_lite_bridge`，保持唯一后端事务及锁存目标。
- [CPU5 顶层封装](../rtl/cpu5_d0_axi_lite_top.v)：原 `cpu5_cached_top` 加新 D0 后端；BASE/WORDS/初始化文件与独立 D0 等待参数明确传递。
- [本阶段合同](cpu5_d0_contract_20261025.md)：请求接受、物理写、响应、复位、功能开关及覆盖边界。

成功 RAM 写在请求接受边沿发生一次；等待或背压不重复写。复位撤销协议状态，保留已经接受的 RAM 写，不清 RAM 或回滚。非法 D0 形状由原端点报错且不回退 AXI。首地址/4 GiB 上边界按原 64 位范围合同处理。该阶段没有改变原核心的退休、年龄、owner、STORE 不可撤销区、Trap、IRQ 和 FENCE 规则。

## 本阶段新仿真实测

所有正常配置及所有变异的编译均为 0 Warning / 0 Error。错误变异和非法参数随后在指定语义/guard 断言处被拒绝，预期 Fatal 不记作正常配置失败。

程序共核验 536603 个周期边沿。功能仿真的时钟设置不证明 FPGA 时序收敛，也不提供性能提升百分比。控制套件专门在 shared reset 下撤销旧 WB；正常结束用例的退休/WB 逐项完全对应，复位弃项单独记账。
