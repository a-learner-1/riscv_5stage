# D0 同步BRAM数据后端：第3步验收

基线：457e73a。D-Cache本体、CPU、本地同步RAM实现保持不变；SoC层在现有D-Cache后新增单事务路由器。0x00010000–0x00013fff进入同步BRAM，其余仍经原AXI4-Lite bridge。

路由锁定受理目标直到响应消费，隔离空闲/未选目标响应；同步BRAM实际写入后才返回成功，CPU仍等响应退休，保留精确STORE异常。未新增写缓冲。

默认ENABLE_D0_BRAM=0保持原平台；独立PDS variant coremark_d0_btb固定为1。D0固件/backend标识双向严格匹配，并在启动读stats+0x1c验证backend ID=1。



功能证据：默认10/10回归PASS；native接口19笔PASS；真实D0 CPU零等待/AXI各通道等待两夹具PASS，8笔RAM STORE均2拍；边界/非法请求/精确异常/接受后复位写保留通过。

受控硬件因果证据：两真实SoC使用同一ROM、相同指令/地址/数据/字节使能和D-Cache；5笔STORE逐笔6→2拍，5次读回、实际写数和Cache账本一致。



真实CoreMark双种子（最终START epoch，原CRC/UART/mtime/退休/冻结快照判据全部保留）：

smoke: cycles 966812→904538（-6.441%）；CPI 1.320242→1.235203；data_write_wait 86094→28698；14349笔STORE全部2拍；退休732299不变。

smoke-validation: cycles 1023007→960825（-6.078%）；CPI 1.302754→1.223568；data_write_wait 85464→28488；14244笔STORE全部2拍；退休785265不变。



归因限制：D0身份检查/打印使内核代码整体+0x28，数据布局+64字节；默认AXI新构建的HEX/DATA与MMIO基线相同。D0与AXI的总窗口差属于候选配置综合实测，不能宣称同二进制纯后端收益。

STORE单项可独立确认削减57,396／56,976拍；剩余净差4,878／5,206拍包含读等待、I-cache、BP和布局影响，不单独归因。D-cache仍有效，miss由321／348变296／324。

两个profile各有13笔含X的STORE数据，基线亦各13笔；观察器按四态源payload和字节掩码逐笔核实物理写。不能把这些数据描述为全部已知数值；原CRC/程序成功门均通过。
