# CPU5 最小 MMIO 与有序设备访问

2026-10-24，基线 `fb5d1a48776b87976b1bdcbe0c98a301d757b753`。状态：**PARTIAL VERIFIED：最小 MMIO 与有序非 RAM**。本轮完成 UART/GPIO/计数器读取、所有非 RAM 访问的最老 MEM 授权及不可撤销 owner；范围见 [本轮合同](cpu5_mmio_contract_20261024.md)。

## 实现与使用

在已有 CPU5 功能配置上加入 `.ENABLE_MMIO(1)`，同时保持 `.SKELETON_ONLY(0), .ENABLE_RAM(1), .EXTERNAL_DMEM(1)`。三路 IRQ、CSR、M 等参数仍按需要显式开启；ENABLE_MMIO 默认 0，默认关闭时外部 D 直连、UART idle、GPIO 零输出及 RAM 越界异常保持原行为。

只有普通 RAM 白名单内的纯 LOAD 允许 EX 提前请求。所有 STORE、设备 LOAD、Stats/未知地址读写都在最老 MEM 首次呈现；非 RAM 读不能因为“非本地 MMIO”而被当成可投机纯读。MEM 保存完整地址/数据/尺寸/strobe/实际读写方向，LOAD 仍按 LOAD 返回 GPR 和 cause5。

唯一 D owner 从首次呈现起将 IO 读写标为不可撤销，历史 `store_lock` 名称现在覆盖 STORE 或 IO。held 请求、等待响应、成功完成但 MEM/WB 回压三个阶段都保持该锁；覆盖它的 flush 被拒绝，IRQ 等待先退休。错误响应以同一个最老 owner 的 PC/地址进入同步 Trap 并确认释放，不会被误当 killed 吞掉。普通 RAM 纯读的 kill/drain 与成功 LOAD→LOAD 同边沿交接保留；任何 IO/STORE/error/killed-drain 均禁止该捷径。

新 `cpu5_mmio_router.v` 将 `0x20000000..0x200000ff` 送至本地 endpoint，其他 RAM/Stats/未知地址仍从公开外部 D 端口发出。响应按已接受事务保存的路由选择，实时新请求地址不能改变旧响应来源。普通 RAM 配置与本地页重叠由参数 guard 拒绝。

新 endpoint 先捕获完整描述符，下一边沿唯一执行，再保持冻结响应。cycle/instret 返回执行边沿前计数低 32 位；UART RX 返回 pre-pop 队首且只 pop 一次；GPIO 和 TX 只在合法执行边沿生效，响应回压不会重放。UART 忙时写 TX 返回访问错误且零发送。旧 UART/GPIO 五份模块原样复用。

本地地址沿用旧产品：00/04 计数只读，10 TX，14 busy，18 RX_DATA，1c RX_STATUS/W1C，20 OUT、24 IN、28 OE、2c/30/34 SET/CLR/XOR（共同前缀 200000）。除 TX 在准确基址允许 SB/SH/SW 外，设备只接受 aligned LW/SW 和匹配 strobe。未映射、错误方向或宽度均 error、零副作用。

| 回压/年龄 | held、accepted、cached 三阶段不可撤销；12 次覆盖 flush 被拒绝，年轻 cut 可接受；设备/未知读取无 EX 请求；老 ECALL/延迟 RAM fault 压年轻设备读；64 位 seq 跨 bit32；普通 RAM 交接保留 |
| Endpoint 独立 oracle | 40,455 检查；860 接受=859 执行+1 次执行前 reset 取消；859 执行=858 响应+1 次执行后 reset 弃置；808 非法拒绝、51 合法；1061 周期响应回压 |

| 兼容链 | 最终同源从头重跑 IRQ→M→CSR/MRET→Trap→RAM→分支→前递→ALU→IF/默认骨架，含全部前阶段负测，旧 TB/工具未改 |

正常配置零 Error/Warning。预期坏样本/非法配置的 Fatal 和非零退出单独记录，编译/库/语法错误不能冒充语义拒绝。复位场景明确记录接受后未响应项，不把跨 reset 取消的请求伪称全部响应完成；无 reset 的程序事务全部闭合。

程序用物理串行引脚预装两个不同 RX 字节后才开放 IF，执行 GPIO、计数器、TX/RX、外部 Stats/未知读取与两类非法本地访问。独立解释器直接解码机器字，设备值由软件 GPIO/FIFO 模型生成；动态 cycle 由端点执行的独立周期编号生成，instret 由已经独立验证的退休前缀计算，不用 DUT 返回值生成期望。

Stats fixture 故意延迟响应，在其接受后拉高外部 IRQ，形成候选但由不可撤销事务阻挡；该读成功退休后下一边沿进入 IRQ，mepc 为程序中独立固定的下一 PC。Handler 保存 CSR 并 MRET；同步设备错误也精确进入并跳过坏指令继续。错误路径上的年轻 pop/未知读取首次呈现为零。fixture 的 Stats 常数返回只用于有序协议验证，不是 Stats 设备实现。

独立集成审查检查了 RAM 末字节白名单、MEM 授权、不可撤销锁与错误释放、交接双方分类、保存响应路由、reset 及组合依赖，未发现阻断项。
